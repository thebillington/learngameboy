Running Code

< Getting Started

One of the biggest barriers to entry for any prospective programmer isn't writing their first program in a new language, but understanding what tools they are going to need and how to install them. We have dedicated this section entirely to explaining the tools you are going to need to familiarise yourself with in order to get your first sample program up and running, as well as where to find and how install them.

There are a number of important tools and utilities you will need to familiarise yourself with which are underlined briefly below. If you are already familiar with the ideas in this section and wish only for recommendations for tools and software to use then in each section we have made recommendations for the best Editors, Assemblers and Emulators for you to use when following these tutorials. More detailed information and installation instructions can be found in the menu at the bottom of the page.

All of this software is recommended as we use it ourselves, but this doesn't make it objectively the best software available and we aren't recommending it to the exclusion of all others. Each programmer has their own preferences and if you don't like a recommended piece of software then do some research and try out your own. There is plenty of software out there, you will find some that you like.

Code Editor - Visual Studio Code

A code editor does exactly what it says on the tin; it allows you to edit code. For this purpose we couldn't recommend anything other than Visual Studio Code, the Open-Source solution developed by Microsoft for Mac, Windows and Linux. One of the key tools of any modern day editor is syntax highlighting which helps with identifying keywords in your code and spotting simple spelling mistakes. Visual Studio Code has an excellent plugin for gbZ80 developed by Donald Hays, with a wealth of tools to support writing and debugging code.

Assembler - RGBDS

Once your code is written you need to translate it into a format that can be understood by the Game Boy. Enter the big daddy of Game Boy programming, Rednex Game Boy Development System. RGBDS is an assembler, used to convert your gbZ80 into a format that can be understood by Game Boy hardware. Written and maintained by Eldred Habert there is no better option for Anassembling your gbZ80 into a Game Boy ROM.

ROM stands for Read Only Memory, so called because Game Boy cartridges contain a very small block of memory that can only be read from. This ROM holds data in a special format called machine code that is readable by the Game Boy CPU.

Emulator - BGB

Anyone who knows anything about video games will have heard the term emulator countless times before. This is because emulators are an incredibly powerful way of playing old games without needing to purchase the hardware. This is because anything that can be done with complex circuitry can also be done with software, although usually in a much more complex and roundabout way.

There is a huge community around game console emulation and the Game Boy is no exception. But just as with game remakes you get some incredible work and some less than perfect. We haven't tried a large range of emulators, but bgb is the go-to since it has accurate emulation of the original hardware and excellent debugging tools.

Running on real hardware

For me, running my own games on real hardware was the ultimate goal and the whole reason I started learning to write code for the Game Boy in the first place. However, there are so many options to choose from when it comes to selecting a flash cart that it can be difficult to actually settle on one. Eventually I went for an Everdrive X3 by Krikzz, but each type of cart has their own price and associated costs and benefits.

In this section we will look at some of the available options, the best options may be for different needs and the process we go through to get assembled ROMs running on real hardware.
