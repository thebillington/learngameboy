Hardware

The key to learning to write code for the Game Boy is to develop a good understanding of how the hardware works as well as the software. In fact, without understanding the CPU and memory map in detail it would be next to impossible to write or debug games in gbZ80 with any level of competency. In this section you will learn everything you need to know about the Game Boy hardware in two parts.

Overview

  • How the CPU works
  • What the memory map is
  • How to send data to the screen
  • How to make effective use of RAM

Advanced

  • Using interrupts to halt and continue execution
  • How to check the state of the buttons
  • Using the OAM to draw sprites
  • How to make use of ROM banking

The hardware overview is perhaps the most important section of the site to read in full before moving on as it is critical to understanding the physical principles of the Game Boy and is therefore your link to understanding how gbZ80 Assembly code is executed to achieve intended results. The advanced hardware section is also incredibly important, but the bulk of information won't necessarily be applicable or completely relatable until you know how to put the basic concepts into practice, so this section will be referenced regularly throughout the tutorials as and when applicable.
