Hex

< Maths

Remember that the binary number system uses a base of 2 and denary uses a base of 10. The next number system we are going to look at is hexadecimal which is also known as base 16. The prefix dec means ten and (if you remember learning about shapes in school) then you may recall that a hexagon is a shape with six sides. If we add hex and dec together then we get 6 + 10 = 16.

When we looked at binary we calculated the place value of each of our columns using base 2:

  • 1st column: 1
  • 2nd column: 1 * 2 = 2
  • 3rd column: 2 * 2 = 4
  • 4th column: 4 * 2 = 8
  • 5th column: 8 * 2 = 16
  • 6th column: 16 * 2 = 32
  • 7th column: 32 * 2 = 64
  • 8th column: 64 * 2 = 128

In hexadecimal we will use 16 instead to calculate our place values:

  • 1st column: 1
  • 2nd column: 1 * 16 = 16
  • 3rd column: 16 * 16 = 256
  • 4th column: 256 * 16 = 4096

Remember we calculate the place value of each column by multiplying the base by the value of the previous column.

Next, just as we did with our binary numbers, let us now put these place values into a table. Remember we populate our columns from right to left:

4096 256 16 1
- - - -

So what happens when we populate our columns with values? Lets explore the hex number 25:

4096 256 16 1
0 0 2 5

Here you can see that we have two 16s and five 1s:

(2 * 16) + (5 * 1) = 32 + 5 = 37

But what happens if we want to represent the number fifteen in hexadecimal? We can only put up to nine in our units column:

4096 256 16 1
0 0 0 9

And if we put a 1 in our second column then we would jump straight to 16:

4096 256 16 1
0 0 1 0

The issue is that we need to display 15 digits, but we don't have a number to represent it, therefore we use a letter:

4096 256 16 1
0 0 0 F

In fact, we will use letters to represent all of our numbers from 10-15:

If we wanted to represent a value of 173 in hexadecimal we will first need to calculate how many times 16 goes into 173:

16 * 10 = 160

And then we will put the remainder in the units column:

4096 256 16 1
0 0 A D

We can now confidently state that:

HEXADECIMAL AD = 173 DENARY

To practice what you have learned try and calculate the value of these hexadecimal numbers (mouseover or click to reveal the answer):

7A = 122
4B7 = 1207
A71D = 42781

To make it a bit more clear what number system we are using binary numbers will be preceded by a percent sign and hexadecimal will be preceded by a dollar sign:

$A7 = 167 = %10100111
