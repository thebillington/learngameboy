Getting Started

When first learning to write code for any system the task can seem like a daunting one, especially for those with little or no prior programming experience. The fact that the Game Boy system is (at the time of writing) 30 years old makes the prospect of learning to write games for it even more intimidating as it can be very difficult to find good sources of information.

Many of the tutorials we used when learning to write code for the Game Boy ourselves would have excellent introductions, before stating that they would be completed at a later date. This meant that when transitioning from writing sample Hello World type programs to developing our own graphics, implementing sprites and detecting button presses we had to do much of the learning ad-lib, taking inspiration from multiple sources and doing our own investigations using the bgb debugger to implement new functionality.

That isn't to say that there aren't excellent resources already available. In fact, you can check out the Awesome Game Boy List to see a full breakdown of everything home-brew for the Game Boy. There are also many examples of Game Boy source code that can be found online and on Github that include source code for how to achieve near enough anything in gbZ80 ASM - however the issue with these demo source codes is that they often aren't fully commented, or require hours of study to decipher.

It is important to bear in mind that what works for one won't necessarily work for another, therefore if you struggle to engage with these tutorials or feel they are too advanced you can always try out other resources. Our starting point for Assembly programming on the Game Boy was the excellent Eldred tutorial, however it ends just as it is about to get to the real meat of gbZ80 programming. If you want to check it out and follow through make sure to head back here when you're finished to help make the transition to writing more complex code.

Will all that said and done this website aims to be a one stop shop for Game Boy development in ASM with tutorials that go past the Hello World phase and teach you how to develop fully fledged Game Boy games. When you are ready to get started, take a look at the menu at the bottom of this page for your next steps in learning. Each page has a menu after it of child pages that relate in subject matter to the overall section you are currently browsing.

In this section we will start to understand why it is a good idea to start programming with gbZ80 Assembly, differences in Game Boy programming to modern day languages and what tools you are going to need to get started writing and more importantly running code for the Game Boy. There is also some pre-requisite mathematical knowledge you will need to get your head around as well as a brief history of the Game Boy, developments made over its lifetime and some of the mods available for each model.
