Binary

< Maths

Anyone who is familiar with the prefix bi will know that it means two. A biplane is a plane with two wings, a bisexual is someone attracted to two genders, a bicycle has two wheels and you guessed it, the binary number system is also known as base 2.

Since we already understand the base principles of a number system from the previous section, let us know examine base 2 and apply the four principles we saw above to a number system with a different base.

The number of possible digits for any given column is the same as the base of the number system (0 to 9 = 10 individual digits)

In denary we used base 10, which gives us 10 possible digits to place in each column (0-9). In binary we will be using base 2, which means that for any individual column we will only be able to use two values. The two values that we are going to select are 0 and 1. Where in denary I can have a number such as 237, with two in the first column, three in the second column and seven in the last column, in binary this wouldn't be possible as I am only allowed to place a 0 or a 1 in each column e.g. 10100010.

When examining binary numbers we don't refer to the value of each individual column as a digit but as a bit. This makes a lot of sense when we examine the word bit as we can see it in an infliction of the words binary digit. Bit is short for binary digit. In the example binary number 10100010 we would refer to this as an 8-bit number as we can see there are 8 binary digits (8-bits). 8-bits is also known as one byte. You will see these terms regularly throughout these tutorials and other Game Boy documentation so make sure to familiarise yourself with them.

We calculate the place value of a column by multiplying the place value of the previous column by the base (always starting with a place value of 1 for our first column)

When we looked at denary we calculated the place value of each of our columns by performing the calculations:

  • 1st column: 1
  • 2nd column: 1 * 10 = 10
  • 3rd column: 10 * 10 = 100
  • 4th column: 100 * 10 = 1,000
  • 5th column: 1,000 * 10 = 10,000
  • ...

For binary we calculate the place value of each column by multiplying the place value of the previous column by the base (remember binary is base 2):

  • 1st column: 1
  • 2nd column: 1 * 2 = 2
  • 3rd column: 2 * 2 = 4
  • 4th column: 4 * 2 = 8
  • 5th column: 8 * 2 = 16
  • 6th column: 16 * 2 = 32
  • 7th column: 32 * 2 = 64
  • 8th column: 64 * 2 = 128

Just as we did with our denary numbers, let us put these place values into a table where each column has the calculated place value. Remember, we populate our columns from right to left:

128 64 32 16 8 4 2 1

And now that we have place values for each column we can put the digit of each column in for our binary number 10100010 (reading from left to right):

128 64 32 16 8 4 2 1
1 0 1 0 0 0 1 0

You calculate the value of each column by multiplying the digit in the column by the place value

Just as with our denary number we now need to multiply the digit in each column by the place value of that colum to calculate the column total:

Place Value 128 64 32 16 8 4 2 1
Digit 1 0 1 0 0 0 1 0
Column total 128 0 32 0 0 0 2 0

We calculate the total of a number by adding up the value of each of its columns

Then we add them all up to give us the total denary value:

128 + 32 + 2 = 162

Notice that the numbers we have for our place values are written in denary, therefore when we use this method to calculate the value of a binary number we are actually converting from binary to denary.

We can now confidently state that:

BINARY 10100010 = 162 DENARY

To practice what you have learned try and calculate the value of these binary numbers (mouseover or click to reveal the answer):

01010011 = 72
11001101 = 205
01100111 = 103
